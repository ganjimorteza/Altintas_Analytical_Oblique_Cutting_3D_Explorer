# Deployment checklist (before emailing Prof. Altintas)

- [ ] Check `index.html` renders correctly with coordinates `Xw,Yw,Zw` (fixed workpiece) and `x,y,z` (local Altintas frame).
- [ ] Upload all files at repository root, without uploading the ZIP file itself.
- [ ] Set repository visibility to **Public** if it is currently private.
- [ ] Enable **Settings → Pages → Deploy from a branch → main / (root)**, then wait for deployment.
- [ ] Open the **published website link** in a new private/incognito browser window; change `i`, `alpha_n`, and `beta_a` and verify that angle/force outputs update without errors.
- [ ] In the repository, review `README.md`, technical note, verification script, and choose an appropriate software/documentation license.
- [ ] Only after scientific and graphical checks, release/archive the exact version in Zenodo and use the issued DOI in the email.

**Important:** This package is a mathematical consistency demonstration, not an experimental validation or proof of novel priority. GitHub publishing does not automatically create a Zenodo DOI.
